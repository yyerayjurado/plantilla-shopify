# Cómo hacer que Claude Code monte tu tienda

1. Descomprime esta carpeta en tu ordenador (por ejemplo en Documentos).
2. Abre Claude Code (la app de escritorio o la terminal) y elige esta carpeta `yaen3d-shopify` como proyecto.
3. Escríbele esto:

> Lee CLAUDE.md y monta mi tienda de Shopify con el tema de esta carpeta. Mi tienda es: xxxxx.myshopify.com

4. Cuando se abra el navegador, inicia sesión en Shopify y pulsa Autorizar. Lo demás lo hace él.

Te pedirá en un solo mensaje lo que falte (tu nombre y NIF para los textos legales, precios y fotos).
